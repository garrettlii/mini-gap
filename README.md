# Mini-GaP

Laptop-scale Graph-as-Policy in MuJoCo: LLM agents write robot policies as skill graphs,
simulator rehearsal grades them, per-node diagnosis drives repairs, and a learned arbiter
decides per node whether a scripted skill or a learned policy should act. A small Qwen model
is fine-tuned with GRPO on simulator rewards to take over graph repair.

Builds on [GaP](https://arxiv.org/abs/2607.05369), [CaP-X](https://capgym.github.io/), and
[AW-0](https://arxiv.org/abs/2610.30136).

## Quickstart (Apple Silicon Mac)

```bash
./scripts/setup_mac.sh                      # tools, Python env, Menagerie Panda, sanity checks
uv run mjpython scripts/view_workcell.py    # interactive viewer
uv run pytest                               # phase 0 tests
uv run pytest --phase 7                     # all contract tests (add --runslow for sweeps)
```

Models are local MLX Qwen checkpoints named in `configs/models.yaml` (no paid APIs).

## Layout

| Path | Layer |
| --- | --- |
| `assets/franka_emika_panda/workcell.xml` | Scene: table, cubes, zones, cameras |
| `gap/sim` | Workcell, IK, task sampler, success checks, oracle |
| `gap/skills` | Typed skill library with pre/post checks |
| `gap/graph` | Graph schema, edits, validator, interpreter |
| `gap/agents` | LLM wrapper, planner, node specialist, critic |
| `gap/rehearsal` | Parallel rehearsal, diagnosis, self-learning loop |
| `gap/train` | SFT data and GRPO reward for Qwen on MLX |
| `gap/arbiter` | Learned fallbacks, paired data, arbiter, six policies |
| `gap/eval` | Splits, eval runner, report |
| `docs/` | Spec, progress log, decision log |

## Results

Every number below is generated by `uv run python -m gap.eval.report --render README.md`
from `results/*.json` (copies of each run's metrics.json). Success rates on fixed evaluation
seeds (100 per task and split) with Wilson 95% intervals; the overhead camera noise model is
on and every policy uses RGB-D perception. Details and caveats: [docs/WRITEUP.md](docs/WRITEUP.md).

[Demo video](docs/media/demo.mp4) (one minute, dev seeds, made by `scripts/record_videos.py`):
a stack episode with the learned arbiter under camera noise; a seeded grasp-yaw bug failing,
then the same seed after the repair loop's fix; sort on object variants with the executor
named at each node.

## Reproduce

```bash
uv run python scripts/train_arbiter.py --demos 600 --paired 200      # learned grasp + arbiter
uv run python scripts/gen_repairs.py --per-task 60                   # teacher repair data
uv run python scripts/train_repair.py sft  --logs runs/*_gen_repairs/edits.jsonl
uv run python scripts/train_repair.py grpo --logs runs/*_gen_repairs/edits.jsonl \
    --resume runs/<sft>/adapter/adapters.safetensors
uv run python scripts/eval_repair.py --adapters sft=runs/<sft>/adapter grpo=runs/<grpo>/adapter
uv run python scripts/run_loop.py --task place --bug diagonal_grasp --specialist planner_repo
uv run python -m gap.eval.report --publish loop_bugs runs/<one run_loop dir per task and bug>
uv run python -m gap.eval.run_eval --models runs/<train_arbiter> \
    --methods code graph_single graph_multi graph_multi+learned_arbiter
uv run python -m gap.eval.report --publish eval_methods runs/<eval>
uv run python -m gap.eval.report --render README.md docs/WRITEUP.md
```
