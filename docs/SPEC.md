# Mini-GaP spec and phase checklist

Condensed from the build guide. Export the full guide (Markdown) into docs/BUILD_GUIDE.md for
complete context. Each phase ends with something that runs and a number you can log.

## Phase checklist

| Phase | Weeks | Done when | Tests |
| --- | --- | --- | --- |
| 0 Setup | 1 evening | sanity_check passes; viewer opens; local Qwen answers a prompt | `pytest` |
| 1 Workcell | 1–2 | Place oracle >= 95/100 dev seeds; can save an MP4 of any seed | `--phase 1 --runslow` |
| 2 Skills | 3–4 | Place oracle rewritten as skill calls, still >= 95% | `--phase 2` |
| 3 Graph | 5 | place/stack/sort example graphs validate; Place graph within 2 pts of oracle | `--phase 3` |
| 4 Harness | 6–7 | free-form code, single-agent graph, multi-agent graph all run on 4 tasks; first-shot table | written in-phase |
| 5 Rehearsal | 8–9 | loop gains >= 20 pts on one task (held-out seeds); >= 200 edit records | written in-phase |
| 6 Qwen | 10–12 | table: zero-shot 2B, SFT 2B, SFT+GRPO 2B, frontier; trained tasks + held-out sort | written in-phase |
| 6b Arbiter | 13–14 | six policies on every split; learned arbiter's gap to oracle reported | written in-phase |
| 7 Eval | 15–16 | full methods x splits table, 100 seeds/cell, Wilson CIs, 3 videos | written in-phase |

Scope rule: if a phase drags past two weeks, cut scope inside it. If time runs short, cut
Phase 6, never 6b.

## Key contracts
- State dict keys: see gap/types.py. Workcell.get_state() returns exactly those.
- Graph execution semantics: see gap/graph/schema.py docstring. Implicit next-in-list success,
  explicit fail edges with max_retries, refs are "<node>.<port>".
- Edit ops: set_param, swap_skill, insert_after, add_edge, remove_node (gap/graph/edits.py).
- Validator error codes: gap/graph/validate.py CODES. Tests key on them.
- Seeds: rehearsal [0, 50k), dev [50k, 60k), eval [100k, 200k) in per-split blocks.

## Results the write-up needs (fill from metrics.json only)

| Claim | Measured as |
| --- | --- |
| Learned arbitration beats validity-only gating | success on pose + object splits, Wilson 95% CI |
| No cost on nominal scenes | nominal success vs best single executor |
| Small model repairs graphs | GRPO Qwen3.5-2B vs zero-shot 2B vs frontier |
| Graph structure matters | multi-agent graph vs free-form code, same skills |

## Deliverables
1. Public repo; one command reproduces the main table
2. 4–6 page workshop-format write-up (CoRL / ICRA workshops; check deadlines at Phase 6b)
3. 90-second video: a success, a recovered failure, the arbiter switching executors
4. README results table with CIs, generated by gap/eval/report.py
